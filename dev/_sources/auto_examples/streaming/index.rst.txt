Streaming / Real-Time Analysis Examples
=======================================

These examples demonstrate tttrlib's streaming consumers, which accept photons
one at a time and maintain incremental state for real-time analysis.

Files
-----

- ``plot_streaming_correlation.py`` — Online multi-tau FCS correlation
- ``plot_streaming_bursts.py`` — Sliding-window burst detection
- ``plot_streaming_flim.py`` — Incremental TCSPC decay histogram and FLIM phasor

A combined Jupyter notebook tutorial is at ``doc/streaming_tutorial.ipynb``.

All examples use synthetic data and run without test files.
