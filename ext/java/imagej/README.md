# tttrlib ImageJ / Fiji plugin

A [Fiji](https://fiji.sc) plugin that reads time-tagged time-resolved confocal
(CLSM) files — PicoQuant PTU/HT3, Becker & Hickl SPC, Leica SP5/SP8 — with the
tttrlib C++ engine via JNI.

> **Fiji is required.** The commands are SciJava `Command` plugins discovered
> through annotations; a plain ImageJ 1.x install has no SciJava layer, so they
> never appear in its menu.

**User documentation — install, commands, options, Java API — lives in the
published docs: [`doc/imagej-plugin.rst`](../../../doc/imagej-plugin.rst).**
This file covers the local build only.

## Layout

```
pom.xml                      Maven build (pom-scijava parent)
benchmark.ijm                Fiji macro that times the reader
src/main/java/…/imagej/      SciJava Commands + the Dataset bridge
src/main/java/…/imagej/core/ Headless reconstruction (no ij.* / net.imagej.*)
src/test/java/…              Headless JUnit tests
```

The SWIG proxies (`src/main/java/io/github/fluorescencetools/tttrlib/*.java`) and
the JNI natives (`src/main/resources/native/`) are **generated by CMake and staged
in before packaging** — both are gitignored; never commit them.

## Build

```sh
# from the repository root
cmake -S . -B build-java -G Ninja \
  -DBUILD_PYTHON_INTERFACE=OFF -DBUILD_JAVA_INTERFACE=ON \
  -DBUILD_LIBRARY=OFF -DBUILD_PHOTON_HDF=OFF -DCMAKE_BUILD_TYPE=Release
cmake --build build-java --target tttrlibJava

DST=ext/java/imagej/src/main/java/io/github/fluorescencetools/tttrlib
cp build-java/java-pkg/src/main/java/io/github/fluorescencetools/tttrlib/*.java $DST/
cp ext/java/pkg/src/main/java/io/github/fluorescencetools/tttrlib/NativeLoader.java $DST/

# Name the native as System.mapLibraryName expects for the target platform:
#   linux-x86-64/libtttrlibjni.so
#   darwin-x86-64/, darwin-aarch64/libtttrlibjni.dylib   (.dylib, not .jnilib)
#   win32-x86-64/tttrlibjni.dll
mkdir -p ext/java/imagej/src/main/resources/native/darwin-aarch64
cp build-java/java-pkg/native/libtttrlibjni.* \
   ext/java/imagej/src/main/resources/native/darwin-aarch64/libtttrlibjni.dylib

cd ext/java/imagej && mvn package
```

The JAR lands in `target/tttrlib_ImageJ-<version>.jar`. CI does the same across
four platforms and ships one cross-platform JAR; `NativeLoader` extracts the
right native at run time.

## Test

```sh
TTTRLIB_DATA=/path/to/tttr-data mvn test
```

Tests build a *restricted* SciJava `Context` — a full one tries to start
`LegacyService`, which needs a real Fiji environment and fails headlessly.

## Install locally

Copy the JAR into `Fiji.app/plugins/` and restart, or drag it onto the Fiji main
window. Commands appear under **Plugins ▸ tttrlib**.

## CLSM auto-configuration

Correct reconstruction of PicoQuant PTU/HT3 images needs CLSM markers and pixel
dimensions read from the file header (`ImgHdr_LineStart`, `ImgHdr_LineStop`,
`ImgHdr_Frame`, `ImgHdr_PixX`, `ImgHdr_PixY`). That logic used to live only in the
Python wrapper, so Java/R/native C++ produced a wrong geometry from the raw
defaults. It now lives in the C++ `CLSMImage` constructor (`src/CLSMImage.cpp`),
so this plugin reconstructs the same image as the Python API (verified:
40×256×256, sum 3364714 for the reference HT3 file). Passing explicit
markers/dimensions still overrides the header-derived values.
