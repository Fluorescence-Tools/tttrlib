template<typename T >
void SwapEndian ( T &  val)

Swaps the endianness of a given value.

This function takes a reference to a value of any type T and swaps its byte order between little-endian and big-endian formats. It uses a union to access the raw bytes of the value and reverses the byte order using std::reverse_copy.

Template Parameters
TThe type of the value whose endianness is to be swapped. Must be trivially copyable and have a defined byte size.
Parameters
valA reference to the value whose endianness is to be swapped. The value is modified in-place.

Example:

int32_t original = 0x12345678; SwapEndian(original); // original now contains 0x78563412
