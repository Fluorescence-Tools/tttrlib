# `imaging` — Image Processing and CLSM Submodules

Top-level module directory for fluorescence lifetime imaging (FLIM), confocal laser scanning microscopy (CLSM), super-resolution, and localization algorithms.

## Submodules

- **`clsm`**: Confocal Laser Scanning Microscopy (CLSM) image reconstruction and pixel phasor analysis.
- **`superres`**: Super-resolution microscopy data handling.
- **`localization`**: Single-molecule localization microscopy (SMLM) fitting routines.
