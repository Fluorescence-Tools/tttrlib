# `io/store` — DataStore Columnar Table Container

`DataStore` column-oriented table memory data structure for analysis results (burst tables, correlation curves, FLIM histograms).

## Contents

- **`io_store.h` / `io_store.cpp`**: `DataStore` and `Column` C++ implementations supporting zero-copy NumPy/R array views.

## Dependencies

- Depends on `util`.
