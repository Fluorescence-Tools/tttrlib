# `io/be` — Becker & Hickl File I/O

Reader implementation for Becker & Hickl SPC file formats (SPC-130, SPC-140, SPC-150, SPC-830, SPCM).

## Contents

- **`io_be.h` / `io_be.cpp`**: Header parser and 32-bit/48-bit record decoder for Becker & Hickl SPC files.

## Dependencies

- Depends on `io/base`, `util`.
