# `io/pq` — PicoQuant Format I/O

This module implements reader and writer support for PicoQuant file formats: PTU, HT3, PT3, PT2, HHT3, and HHT2.

## Contents

- **`io_pq.h` / `io_pq.cpp`**: Header parsing, tag handling, and record decoding for PicoQuant TTTR files.

## Dependencies

- Depends on `io/base`, `util`, nlohmann/json.
